title: Codegen configuration

The `codegen` section configures automatic code generation from your database
types. When enabled, the CLI checks whether generated files are stale before
running any project command (`dev`, `push`, `pull`, and others) and
regenerates them silently if needed.

## Basic configuration

```json title="supabase/config.json"
{
  "codegen": {
    "validation": "zod",
    "plugins": ["tanstack"]
  }
}
```

Generated files are derived from `supabase/types/database.ts`. The CLI
regenerates them automatically whenever `database.ts` is newer than the output
files — you don't need to run a separate command.

## Zod validation schemas

Setting `validation` to `"zod"` generates `supabase/types/schema.ts` with a
Zod schema for every table and enum in your database.

```json title="supabase/config.json"
{
  "codegen": {
    "validation": "zod"
  }
}
```

For each table, the CLI generates one schema using the row shape. Fields that
are optional on insert (columns with defaults or that are nullable) are marked
`.optional()`:

```ts title="supabase/types/schema.ts"
import { z } from 'zod'

// Todos schema
export const todosSchema = z.object({
  id: z.number(),
  text: z.string().nullable().optional(),
  completed: z.boolean().nullable().optional(),
  created_at: z.string().optional(),
})

export type Todos = z.infer<typeof todosSchema>
```

You must install `zod` in your project for the generated file to compile:

```bash
npm install zod
```

## TanStack DB

Adding `"tanstack"` to `plugins` generates `supabase/lib/db.ts` with a
TanStack DB instance wired up to your Supabase client. Each table gets its
own typed collection.

```json title="supabase/config.json"
{
  "codegen": {
    "plugins": ["tanstack"]
  }
}
```

The `"tanstack"` plugin requires `"zod"` validation to also be enabled, since
the generated collections reference the Zod row schemas.

```ts title="supabase/lib/db.ts"
import { supabaseCollectionOptions } from 'supa-tdb-collection'
import { createClient } from '@/lib/supabase/client'
import { todosSchema } from '../types/schema'
import { createCollection } from '@tanstack/db'

export const todosCollection = createCollection(supabaseCollectionOptions({
  tableName: "todos",
  getKey: (item) => item.id!,
  where: (query, item) => query.eq("id", item.id),
  schema: todosSchema,
  realtime: true,
  supabase: createClient,
}))
```

You must install both packages:

```bash
npm install @tanstack/db supa-tdb-collection
```

For a full walkthrough including React usage, see the
[TanStack DB guide](/docs/config/tanstack-db).

## Reference

All properties live under the `codegen` key in your config file:

| Property | Type | Default | Description |
|---|---|---|---|
| `validation` | `"zod"` | — | Generates Zod schemas in `supabase/types/schema.ts` |
| `plugins` | `string[]` | `[]` | Additional generators. Supported value: `"tanstack"` |
| `tanstack.client_path` | `string` | `"@/lib/supabase/client"` | Import path for your Supabase client |
| `tanstack.client_function_name` | `string` | `"createClient"` | Name of the exported client function |
